# MANIFEST: Games 5 to 10 Source Code

This archive contains a fully buildable, standalone Flutter project that includes only the original source codes and assets for minigames 5 to 10 from the '3minutes' project.

## 5. Mirror Control
- **Entry Point:** lib/features/minigames/presentation/mirror_control/mirror_control_minigame.dart
- **Dependencies (Internal):** 
  - lib/features/minigames/presentation/mirror_control/mirror_control_engine.dart
  - lib/features/minigames/presentation/mirror_control/mirror_control_painter.dart
- **Assets:** ssets/mirror_control/ (player.png, enemy.png, exit.png, target.png, obstacle.png)
- **Orientation:** Responsive (Supports Portrait & Landscape)
- **Rounds/Stages:** Generated randomly based on seed (Endless)
