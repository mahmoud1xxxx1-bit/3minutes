# Quick Match policy

- 1v1 random matchmaking only.
- Uses the same deterministic 3-minute / 8-mini-game runtime and evidence validation as competitive play.
- Never changes RP, rank tier, seasonal leaderboard placement, peak rank, or Legendary prestige history.
- Rewards: win 18 Coins + 70 XP; tie 12 Coins + 50 XP; loss 6 Coins + 30 XP.
- Same-opponent anti-farming: first 10 matches per UTC day receive 100% Quick reward; matches 11–20 receive 25%; subsequent same-pair matches receive no Coins/XP for that UTC day.
- Quick queue, evidence, settlement, and pair-usage documents are server-authoritative.
- Quick matchmaking is available only when secure Blaze authority is enabled/deployed; the client does not silently fall back to client-authoritative rewards.
