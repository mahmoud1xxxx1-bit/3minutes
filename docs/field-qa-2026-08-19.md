# 3 Minutes — Device Field QA Remediation Ledger

Date: 2026-08-19
Status: IN PROGRESS
Source: physical Android device testing after validated debug APK.

This ledger records issues discovered by real-device testing after the previous CI closeout. It is intentionally separate from CI evidence: a green build does not prove visual quality, first-run polish, navigation discoverability, asset loading latency, or audio experience.

## Confirmed device findings

1. Avatar artwork quality is below the intended premium visual bar for several of the 45 avatars.
2. Avatar/shop artwork can show loading spinners while browsing; first experience is not acceptably prewarmed.
3. Premium Season Pass is not discoverable enough from the Season surface even though its component exists inside the Progression screen.
4. Internal infrastructure terminology is visible to players (including Spark/Blaze/server-authority wording). This must never be player-facing.
5. Sign out occurs without a confirmation dialog.
6. Daily/weekly missions can become stuck behind an indefinite season-loading spinner when no current season document is available to the current backend.
7. No dedicated player Settings screen exists.
8. No persistent music/SFX volume controls exist.
9. No main-menu ambient music or in-match focus music is wired.
10. Legacy profile editing still contains obsolete `default_01..04` avatar IDs, conflicting with the approved 45-avatar ownership catalog.

## Remediation policy

- No internal Firebase plan names, backend phases, deployment gates, or Cloud Functions terminology may appear in player-facing copy.
- Player-facing unavailable states must use neutral product language only.
- Missions/Progression must fail soft and must never show an endless spinner solely because no live season is returned.
- Premium Season Pass must be surfaced prominently from Season, not hidden behind a tertiary tab.
- Avatar artwork must be preloaded before the player enters the main shell; normal catalog browsing must not show repeated decode spinners.
- Avatar identity changes must use the approved cosmetic ownership system only.
- Settings will own persistent music volume, SFX volume, mute controls, and related user preferences.
- Sign out must require explicit confirmation.
- Audio must be cosmetic/experiential only and must never affect timing or competitive state.

## Validation required before closeout

- Functions tests / Firestore security regression.
- Flutter Analyze.
- Flutter Tests including settings/preload/navigation tests.
- Real APK build.
- Device verification of avatar loading, Premium discoverability, Missions navigation, Settings, sign-out confirmation, and audio controls.

This file must be updated continuously during remediation and marked COMPLETE only after the replacement APK is produced and device-facing fixes are validated.
